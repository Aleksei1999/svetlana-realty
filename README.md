# Светлана Изоткина · Доходная недвижимость

Два самостоятельных варианта сайта образовательных программ «Старт» и «Магия доходной недвижимости».

## Открыть сайты

- **[Вариант 1 — архитектура и стратегия](https://aleksei1999.github.io/svetlana-realty/variant-1/)**
- **[Вариант 2 — портрет и движение](https://aleksei1999.github.io/svetlana-realty/variant-2/)**
- [Страница выбора двух вариантов](https://aleksei1999.github.io/svetlana-realty/)

Сайты доступны без входа в ChatGPT. GitHub Pages публикует корень ветки `site-variants`; изменения в этой ветке автоматически обновляют сайты.

| Вариант | Исходники | Предыдущая публикация в Sites |
| --- | --- | --- |
| 1 — архитектурная композиция, бордовая палитра | [variant-1](variant-1/) | [Открыть в Sites](https://svetlana-realty-start.ammfund.chatgpt.site/) |
| 2 — крупный портрет и анимации прокрутки | [variant-2](variant-2/) | [Открыть в Sites](https://svetlana-realty-motion.ammfund.chatgpt.site/) |

Предыдущие публикации в Sites могут требовать входа в ChatGPT. Исходники запускаются независимо от ChatGPT и не требуют сборки.

## Запуск

Из корня репозитория выполните:

```sh
python3 -m http.server 8080
```

Затем откройте:

- Первый вариант: http://localhost:8080/variant-1/
- Второй вариант: http://localhost:8080/variant-2/

Каждую папку можно разместить отдельно на обычном статическом хостинге. В качестве каталога публикации укажите `variant-1` или `variant-2` соответственно. Команда сборки не нужна.

## Структура

```text
variant-1/  HTML, CSS, JavaScript и изображения первого варианта
variant-2/  HTML, CSS, JavaScript, локальные шрифты и изображения второго варианта
docs/       Шаблон таблицы с листами «Заявки» и «Оплаты»
previews/   Скриншоты вариантов
```

## Текущее состояние

- Адаптивная верстка, анимации, карточки, FAQ и модальные анкеты реализованы.
- Формы работают как предпросмотр: проверяют поля, но не отправляют и не сохраняют данные.
- ЮKassa пока не подключена, приём оплаты не открыт.
- Файл Excel подготовлен для импорта в Google Таблицы. Автоматическая запись заявок и оплат ещё не подключена.
- Во втором варианте добавлены четыре видеоотзыва: Ирина, Антон, Алексей с женой, Алёна и Константин. Ролики запускаются по нажатию; при старте следующего предыдущий останавливается.
- Перед приёмом заявок и оплат необходимо добавить реквизиты, оферту и политику обработки данных, подключить серверную обработку и платёжный сервис. Секретные ключи следует хранить на сервере, а не в HTML или JavaScript браузера.

## Материалы

Фото эксперта использовано из предоставленного пользователем портрета с удалённым фоном. Архитектурные и интерьерные изображения являются концептуальными иллюстрациями, а не портфолио объектов эксперта.

Второй вариант использует Host Grotesk и Manrope для кириллицы. Лицензии шрифтов находятся в папке `variant-2/assets/licenses/`.
